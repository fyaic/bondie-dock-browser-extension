### Phase 9 Local Bondie visibility

- `02e7d85 Add local Bondie visibility policy wiring`
- Session Bridge local commit: `cb4c953 Support all-sessions visibility policy`
- Session Bridge follow-up commit: `03b12ff Speed up all-sessions visibility listing`

产物：

- Browser Options 增加 `Local Bondie relationship`，支持 `服务关系` / `从属关系`。
- Browser Session Bridge query/action payload 增加 `visibility_policy`。
- Session Bridge `/v1/sessions` 支持 `visibility_policy=all_sessions`。
- 默认 `communication` 仍映射 `participant_sessions`，保持 scoped 查询，不因 Phase 9 打开全量权限。
- `subordinate` 映射 `all_sessions`，用于本地私助/Bondie 从属关系验收。
- 全量可见模式下，新开对话必须先选中一条 session 作为 route hint，避免模糊 new。

本地验收口径：

- Options 设置 `Local Bondie relationship=从属关系` 时，Side Panel 应显示本地 Bridge 全量 sessions。
- Options 切回 `Local Bondie relationship=服务关系` 时，Side Panel 应只显示当前 `Route key` scope 相关 sessions；用于模拟 Veil/周威时，需要将 `Route key` 配置为对应用户关系 route。
- 2026-06-22 临时 Bridge `127.0.0.1:18767` 真实 smoke：`all_sessions` 返回 50 条，约 4.0s；`participant_sessions` + 周威 route 返回 17 条，约 6.3s；旧“上下游”示例当前返回 `session_scope_mismatch`，后续验收不要继续用它作为正例。
- 2026-06-22 正式 Bridge `100.79.143.105:8766` 已通过 launchd 重启加载 `03b12ff`，新 PID `11751`。正式地址复测：`/v1/bridge` 含 `list_all_sessions`；周威 scoped 17 条约 6.0s；`all_sessions` 50 条约 3.6s，`history_enrichment_ms=0`。
- 旧 Side Panel 兼容性：不带 `visibility_policy` 的旧请求仍默认走 scoped `participant_sessions`，正式 Bridge smoke 返回周威 route 17 条，不会误切到全量。

边界：

- 已完成的是本地单 Bondie / legacy direct Bridge 的权限切换能力。
- B 侧 Session Bridge 只校验 bearer token、route scope 和 session restore；它不负责 OAuth 用户身份、用户-实例关系判定或多 Bondie bridge selection。
- 标准分发已覆盖每台 OpenClaw 设备部署 Session Bridge、Tailscale/private endpoint、launchd/systemd、smoke 和回滚；多 Bondie 的最终权限管理仍必须走 Bondie Control Plane + OAuth + bridge registry。
